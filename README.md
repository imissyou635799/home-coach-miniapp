# 上门私教服务小程序

标准一期版工程，包含：

- `apps/api`：后端接口，当前使用 Node.js 内置模块和本地 JSON 数据文件，方便快速启动和演示。
- `apps/admin`：管理后台，原生 HTML/CSS/JS，可直接连接后端接口。
- `miniprogram`：微信小程序端，包含教练端和家长端核心页面。
- `docs`：开发、部署、接口说明。

## 快速启动

```bash
npm run dev:api
npm run dev:admin
```

默认地址：

- 后端 API：http://localhost:3100
- 管理后台：http://localhost:3200

## 小程序调试

1. 打开微信开发者工具。
2. 导入 `miniprogram` 目录。
3. 在 `miniprogram/utils/config.js` 中确认 `API_BASE_URL` 指向本地或测试环境 API。
4. 先进入身份选择页，选择教练或家长。

## 重要说明

一期业务边界：

- 平台只收教练会员费。
- 家长课程费不进入平台账户。
- 家长只能看到邀请自己的教练。
- AI 报告、分销、保险正式接入先不做，只预留位置。

生产上线前需要替换：

- 本地 JSON 数据存储改为 MySQL。
- 演示登录改为微信登录和手机号授权。
- 模拟会员支付改为微信支付 JSAPI。
- 文件上传改为腾讯云 COS 或阿里云 OSS。
