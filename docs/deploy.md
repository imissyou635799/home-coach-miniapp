# 部署说明

## 一、上线前准备

1. 微信小程序账号已认证。
2. 小程序备案完成。
3. 微信支付商户号已开通，并绑定小程序 AppID。
4. 域名已备案，并配置 HTTPS。
5. 准备对象存储，用于图片和视频。

## 二、推荐正式环境

- Nginx：处理 HTTPS 和反向代理。
- Node.js 20+：运行 API。
- MySQL 8：保存业务数据。
- Redis：保存登录状态、消息和定时任务辅助数据。
- 对象存储：保存图片和视频。

## 三、当前演示版启动

```bash
npm run dev:api
npm run dev:admin
```

## 四、正式上线需要改造

当前版本为了快速开发和演示，后端使用本地 JSON 文件保存数据。正式上线前建议改为 MySQL，并接入：

- 微信登录。
- 微信支付。
- 微信订阅消息。
- 云对象存储。
- 数据库每日备份。
- 后端错误日志。

## 五、小程序后台配置

需要配置：

- request 合法域名：后端 API 域名。
- uploadFile 合法域名：对象存储上传域名或后端上传域名。
- downloadFile 合法域名：图片视频访问域名。
- 隐私保护指引。
- 订阅消息模板。
